# Dr. Geetha R – Website

This repository contains the static website and its locally stored image assets.

## GitHub Pages deployment

1. Upload `index.html`, `README.md`, and the complete `assets` folder to the **root** of your repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Your website will be published at your GitHub Pages URL.

## Image assets

All nine supplied image files are stored in `assets/images/`. The HTML references these local files, so the site no longer depends on the original Google-hosted image URLs.

Keep the folder structure unchanged when uploading. In particular, do not upload only `index.html`; upload the entire `assets` folder too.
